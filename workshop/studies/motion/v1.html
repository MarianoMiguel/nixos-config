Folio

The desktop as a printed thing. Every image is a plate in one ink; every change is the press at work. Nothing fades. It develops, bleeds, turns, and stamps.

Why a printmaker

Motion from the medium, not from a library of easings.

Folio's art is two colors: paper and one ink, dithered. A great website earns its feel from one idea carried everywhere; ours is that idea. Wallpaper, lock screen, album art and window openings are all prints, so they all move like prints.

Each move below is live, in the real plates and inks, and each says how it would be built on the desktop: a QML ShaderEffect in the shell, or a niri custom-shader for windows.

01 · Develop

A plate arrives dot by dot

On login, on a new wallpaper, on waking: the image is not faded in, it is printed. Ink dots land in random order until the plate is whole, the way a photograph comes up in the tray.

08 · Windows

Windows develop too

niri lets a window's opening animation be a shader, so a new window can print in exactly like the plates, and close by lifting its ink off. This is the one move that reaches every app.

420 ms open260 ms closeniri custom-shader
window-open {
    duration-ms 420
    curve "ease-out-expo"
    custom-shader r"
      vec4 open_color(vec3 coords_geo, vec3 size_geo) {
        vec3 tex = niri_geo_to_tex * coords_geo;
        vec4 color = texture2D(niri_tex, tex.st);
        vec2 cell = floor(coords_geo.xy * size_geo.xy / 2.0);
        float n = fract(sin(dot(cell, vec2(12.9898, 78.233))) * 43758.5453);
        return color * step(n, niri_clamped_progress);
      }"
}

The score

How the desktop assembles after you log in

Like a title sequence: one thing at a time, each starting before the last has finished, so it reads as a single gesture. 1.6 seconds from password to a desktop you can use; input is live from the first frame.

Rule 1

Never fade an image

Images develop, dissolve or bleed. A crossfade between two prints makes a third, muddy one; ours never exists.

Rule 2

Start where the hand is

Bleeds start at the cursor, panels from the edge they belong to, toasts from under the bar. Motion explains where things live.

Rule 3

Input before ornament

Everything is clickable mid-flight. Durations are long enough to read and short enough never to wait on.
